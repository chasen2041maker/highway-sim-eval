DBSCAN 怎么分堆

从天上往下看的一小块路面，点是去完地面后剩下的雷达点（示意数据，不是你那一帧）。拖动两个滑块，看点怎么被分成一堆一堆；点一下任意一个点，看它的圈。

三条规则

  1. 以每个点为圆心，画一个半径 eps 米的圈。圈里（算上它自己）至少有 min_samples 个点，它就是核心点。
  2. 核心点把圈里的点都拉进自己这一堆。被拉进来的点如果也是核心点，就接着往外拉，像传话一样一路传下去。
  3. 谁也拉不到的点，算噪声，堆号是 −1。

输入：每个点的 (x, y)。输出：每个点一个堆号 0, 1, 2, …，噪声是 −1。事先不用告诉它有几堆。

自己拖拖看

同一个颜色 = 同一堆 小叉 = 噪声 大点 = 核心点，小点 = 被拉进来的边缘点 虚线框 = 真东西的位置（算法看不到）
