前车框为什么偏

你跑出来：前车框中心 (12.70, 0.00)，真中心 (15.00, 0.00)，差 2.30 米；框长只有 0.08 米。两张图：侧视看激光打到了前车哪儿，俯视看框为什么只能框住看得见的那几面。

① 侧视：正前方这一条线上，激光打到了哪

打在车尾 能落到车顶的角度缝 飞过车顶

雷达离地 1.8 米，前车车顶离地 1.5 米，只差 0.3 米。激光要落在车顶上（车尾 12.7 米到车头 17.3 米之间），往下的角度必须在 0.99°～1.35° 之间，这条缝只有 0.36° 宽；可相邻两根激光差 1.29°：−0.32° 那根太平，飞过车顶（320 米外才落地，超过 50 米量程）；−1.61° 那根打在车尾 1.44 米高处，比车顶低 6 厘米。所以车顶 0 个点，105 个点全在车尾，你的最高点 z = −0.36 就是 1.44 米高。
