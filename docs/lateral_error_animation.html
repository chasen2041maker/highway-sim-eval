共 7 步 · 看的是结果
  1. 路的方向 d = B − A =
    dx, dy = bx - ax, by - ay
  2. 路长² =
    seg_len2 = dx * dx + dy * dy
  3. 车的中心点相对 A：v = P − A =
    (px - ax), (py - ay)
  4. 把 v 拆成两段：沿着路走了多远（前后），和偏到旁边多远（左右）。先算沿路那段：
    点积 =
    沿路 = 点积 ÷ 路长 =
    t = 沿路 ÷ 路长 =
    一共除了两次路长，所以代码里直接除以路长²
    t = ((px - ax) * dx + (py - ay) * dy) / seg_len2
  5. t 要在 0 到 1 之间（0 = 在 A，1 = 在 B）：
    t = max(0.0, min(1.0, t))
  6. 垂足 F（中心线上正好在车旁边的点）F = A + t × d =
    fx, fy = ax + t * dx, ay + t * dy
  7. 新尺子 = 车到垂足 =
    return math.hypot(px - fx, py - fy)

车沿着路开：两把尺子的读数

  • 老尺子在钉子正旁边时是对的（等于车离中心线多远），在两颗钉子正中间时多报得最多：√(0.30² + 0.25²) = 0.39。
  • 把滑块拖到 0：车压在线上，真实是 0，老尺子还在 0 到 0.25 之间来回跳。
  • 10-16 在 CARLA 里一直报 0.13 米也是这个原因：车每秒正好走 12 个点间隔，每次打印都停在两点之间的同一个位置。
  • 路上有很多颗钉子时，新尺子每一段都量一次、取最小（第 3 步要写的）。
