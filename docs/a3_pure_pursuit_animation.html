三次的最终结果

盯多远（Ld）直道上越过白线最远拐弯时离白线最远毛病

和你在终端里跑 python -m examples.a3_pure_pursuit 打印的数字一样：这一页用同样的公式、同样的设定重算了一遍。

两个数字怎么读

直道上越过白线最远

只看前 30 米直道。车在白线右边时还没碰到线；跑到白线左边，就是冲过头了。取跑到左边最远的那一下。一次都没冲过就是 0。代码里叫 overshoot_m。

拐弯时离白线最远

只看弯道那段（40 米之后、还没拐完）。每一刻量一下车离白线多远，取最远的那一下。代码里叫 curve_err_m。
