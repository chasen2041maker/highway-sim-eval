d前车车尾离我多少米（要估计的第 1 个数）

P有多没把握：钟的宽度。图上写的 ±0.12 是 √P（标准差），P 本身是它的平方
Q每猜一步多出来的没把握：0.1 秒里前车可能加速、减速，所以猜完钟会变宽
z这一帧雷达量到的距离
R雷达量距离的误差：0.2 米，R = 0.2² = 0.04
K这一帧信“量”多少（0～1）。猜的钟窄，K 就小，多信猜；量的钟窄，K 就大，多信量
