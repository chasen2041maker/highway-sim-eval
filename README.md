# highway-sim-eval

基于 [CARLA](https://carla.org/) 的**智驾仿真评测与数据闭环平台**。

包含四部分：一套自己实现的模块化驾驶系统；批量场景评测与录制回灌；多模态数据挖掘；以及用这套平台闭环训练、迭代一个小的端到端模型。

## 要回答的问题

- 同一组场景下，哪套驾驶系统更安全、更顺、更高效？
- 它在什么情况下失败，失败前发生了什么？
- 改完以后是真的变好了，还是只是这次的场景更容易？
- 开环指标（预测轨迹和真值差多少）和闭环表现（真的开起来怎么样）是否一致？

## 计划

### A. 模块化驾驶系统（`ads/`）

- [x] 车辆运动学模型（自行车模型）
- [ ] CARLA 同步模式主循环；坐标系与时间戳；传感器录制
- [ ] PID 速度控制 + Pure Pursuit 横向控制
- [ ] 交通流与跟车
- [ ] 激光雷达感知：地面分割（RANSAC）+ 聚类（DBSCAN）+ 3D 框
- [ ] 多目标跟踪：卡尔曼滤波 + 匈牙利匹配 + 航迹管理
- [ ] Frenet 坐标 + 多项式轨迹：变道与超车
- [ ] 全链打通：感知结果替换真值，俯视图回放

### B. 仿真评测与数据闭环

- [ ] 参数化场景库：邻车加塞、前车急刹、慢车挡路、行人横穿
- [ ] 批量调度：任务队列、超时、失败重试、结果入库
- [ ] 录制与回灌：回放记录数据，对感知和规划做回归
- [ ] 指标：碰撞、TTC、舒适度、路线完成度、驾驶分；置信区间；调参与测试场景分开
- [ ] 回归报告与看板：版本对比

### C. 多模态数据挖掘

- [ ] 视觉语言模型自动打标，并与仿真真值对比准确率
- [ ] 自然语言检索场景
- [ ] 失败归因与场景生成（指标一律由程序计算，模型只负责分类、说明和生成参数）

### D. 闭环学习

- [ ] 用 A 的系统批量采集示范数据
- [ ] 训练小模型：俯视图 / 目标列表 → 未来路径与速度
- [ ] 闭环评测，对比开环误差与闭环表现
- [ ] 挖出失败场景，针对性补数据再训练

### E. 工程

- [ ] C++ 实现的卡尔曼跟踪器（带单元测试，Python 绑定）
- [ ] ROS 2 话题发布与 bag 录制
- [ ] Docker 化的评测客户端

## 设计约定

- 每个模块写清输入、输出、单位、坐标系和时间戳。
- 每个模块都与仿真真值比较，给出误差指标。
- 场景、配置和随机种子固定，结果可以复现。
- 评测指标只从运行记录计算。

## 环境

- CARLA 0.9.16（服务器）+ Python 客户端 `carla==0.9.16`（Python 3.10–3.12）
- 显卡：NVIDIA，显存 8 GB 以上

